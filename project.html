Project

PCM Unified Hardware

PCB terpadu yang menyeragamkan berbagai varian hardware ke satu platform dengan 11 fitur, pinout terstandarisasi, dan arsitektur stackable. Dilengkapi desain enclosure 3D print untuk mendukung prototyping.

Modbus Gateway

Gateway IoT dengan firmware untuk komunikasi Modbus RTU dan TCP/IP, dilengkapi data logging serta dukungan HTTP dan MQTT. Configurable sesuai kebutuhan komunikasi Modbus dan IoT, serta terintegrasi ke aplikasi mobile via BLE dengan dynamic passkey.

IoT Contactor Control

Alat kendali kontraktor via HP yang mendukung mode manual dan otomatis, pakai MQTT Blynk. Konfigurasi Wi-Fi bisa diatur langsung tanpa ubah kode, dilengkapi LED indikator untuk status perangkat.

GitHub

GoKillS — Go Kill Smell

Sistem deteksi gas amonia berbasis IoT untuk toilet umum, meliputi desain perangkat, sistem elektronik, dan firmware mikrokontroler. Terintegrasi dengan ESP32 ke platform Blynk dan Telegram melalui MQTT dan HTTP untuk monitoring serta alerting secara real-time.

GitHub Live Demo

IoT App — MIT App Inventor

Aplikasi IoT berbasis MIT App Inventor untuk monitoring sensor lingkungan secara real-time, lengkap dengan login dan registrasi. Data perangkat diambil dari Thingsboard via HTTP, lalu ditampilkan dalam format list dan grafik.

GitHub

Real-Time Weather Forecast

Sistem IoT untuk akuisisi data lingkungan (suhu, kelembapan, ketinggian lokasi) dan pengiriman ke Firebase sebagai data logging backend. Dirancang untuk integrasi dengan middleware dan model machine learning guna analisis data dan forecasting.
